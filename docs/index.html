Quickstart

Running in three commands

No API key required — Athena runs fully local on Ollama, or against 30+ hosted providers.

# clone, build the native ledger kernel + dashboard
git clone https://github.com/athena-swarm/athena && cd athena
./install.sh

# start the swarm → http://127.0.0.1:8000
./venv/bin/athena up

# or drive it straight from the terminal
athena run "research the top vector databases and write a comparison"
athena verify   # ✓ chain verified · every step signed
Why Athena

What makes it different

Most frameworks give you orchestration and observability. Athena adds two things they structurally don't have — provable provenance and genuine self-extension — and makes both safe by construction.

1 It proves its work

Every action is Ed25519-signed by the agent that took it and appended to a hash-chained ledger. Tamper with a block and the chain breaks. Tracing tells you what a system claims it did; a signed chain lets you prove it.

2 It builds its own tools

When nothing fits, an agent writes a skill. Athena static-capability-checks it, runs its generated tests in the sandbox, and injects it into the live run. Proven skills get promoted; failing ones get repaired and retried.

3 It can't get worse

The harness tunes its own routing, budgets, prompts, playbooks and tool library from outcomes. Every self-modification is evidence-gated, signed to the ledger, and reversible.

4 It doesn't overpay

A sub-millisecond embedding router sends trivial asks to a one-shot responder and only escalates real work to the full swarm — and it learns from mis-routed runs. An opt-in semantic cache answers repeats with zero model calls.

5 Capability-zero sandbox

Model-written code runs in a WebAssembly guest with no ambient authority — it cannot syscall by default. File access is a separate, opt-in jailed workspace with size caps.

6 Yours, and local

Runs entirely offline on Ollama with a native Rust core. No vendor lock-in, no telemetry, Apache-2.0 licensed.
